# v2025.0 - API Version Removed

This API version has been **permanently removed** and is no longer supported.

## What happened?

API version v2025.0 was discontinued on **3rd August 2026** and all its documentation has been removed. This version is no longer available for use.

## What should I do?

Please migrate to the current API version:

* **[v2026.1](/api-docs/v2026.1/)** - The current supported API version

If you need assistance migrating from v2025.0 to the current version, please refer to the [API versioning strategy](/api-docs/v2026.1/api-versioning-strategy.html) documentation.
